# BNAGENT

Independent fair-mint token on BNB Smart Chain for Binance Agentic Wallets holding a `.ai` Agent ID.
**Not affiliated with Binance. No promise of profit. Not deployed yet; not audited.**

- `src/` — `BnagentMint.sol` (Jager-model mint: 1,100 burned shares, pricing, quotas, 20% treasury / 80% pool, automatic pool open at share 10,000 with LP to dead, floor line, tax conversion, admin/renounce, 30-day `withdrawUnfilled()`: after day 30 without share 10,000 the treasury can withdraw the parked 80% repeatedly while minting continues) and `BnagentToken.sol` (BEP-20 with transfer rules and taxes).
- `test/BnagentFork.t.sol` — BSC mainnet fork tests (deploys through the real CREATE2 proxy, real Agent ID holders, Chainlink, PancakeSwap).
- `script/` — mainnet wiring (`BscConfig.sol`) and the unsigned plan generator (`BuildPlan.s.sol`).
- `deploy/bsc-mainnet-plan.json` — unsigned deployment calldata. Nothing has been broadcast.
- `site/` — static website: https://bnagent.onrender.com/ (Render static site, publish dir `site/`) and the GitHub Pages mirror https://653366873iuhm-source.github.io/bnagent/; `site/llms.txt`, `site/agent.md`. Logo, favicons and og image generated by `tools/make_logo.py` + `tools/render_assets.js`.
- `server/` — Binance Agentic Wallet QR-login proxy (Node, no deps), Render web service `bnagent-api` (https://bnagent-api.onrender.com). Env `ALLOW_TO` = mint contract address after deployment.
- `docs/PARAMETERS.md` — every parameter and the scaling math. `docs/DEPLOY.md` — deployment steps. `docs/JAGER-DIFF.md` — audit against the Jager reference.
- `secrets/` — gitignored; encrypted social-signer keystore (never committed).
